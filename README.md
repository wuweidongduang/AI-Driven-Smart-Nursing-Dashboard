# 🏥 AI-Driven Smart Nursing Dashboard (基于长链推理的智能护理大屏)

> **Warning**: This project is entirely generated by a Multi-Agent AI System using Long-Chain Reasoning. It demonstrates how AI can solve complex enterprise software design pain points with zero hallucination.

## 🎯 Core Pain Points Solved
Traditional nurse stations suffer from severe **information fragmentation and cognitive overload**. Nurses must constantly switch between HIS, LIS, and monitoring systems, leading to missed critical alerts and high mental fatigue. This project creates an immersive, "view-only" monitoring dashboard that aggregates fragmented data and prioritizes alerts.

## 🧠 Core Logic: Multi-Agent Collaboration & Long-Chain Reasoning
This project wasn't generated by a single prompt. It uses a **6-stage, 5-gate Harness workflow** with Multi-Agent collaboration:
1. **PM Agent**: Defines boundaries and clarifies requirements.
2. **Architect Agent**: Translates business logic into strict State Machines (Bed_State, Alert_State) and UI structures.
3. **Contract Agent**: Monitors requirement changes dynamically. Evaluates impact and prevents logic collapse during mid-generation modifications.
4. **Coder Agent**: Maps state machines to high-fidelity frontend components.

The reasoning chain depth reaches up to 6 logical steps, ensuring extreme edge cases (e.g., 100-note limits, call/critical value bifurcation) are handled perfectly.

## ✨ Key Features
- **Dual-Track Alert Mechanism**: Bifurcated logic for Calls (Popup + Blink) vs. Critical Values (Marquee + Blink).
- **Dynamic State Machine**: Automatic UI adaptation based on patient status (Empty, Occupied, Alert).
- **Privacy Mode**: One-click PII masking for public display screens.
- **Zero-Hallucination Architecture**: Logic locked by Contract Agent, ensuring high reliability.
